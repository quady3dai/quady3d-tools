## 0.1.0 — 2026-10-23

- First public website release of MCP, Agent Skill, JavaScript / TypeScript SDK and Python SDK under the MIT License.
- Text and single-image quotes, explicit credit limits, original-task recovery and streamed model delivery through API v1.
- MCP terminal connection setup with hidden key input and private local storage; project-scoped file access and no-overwrite delivery.
- Standalone Codex MCP and Skill setup. Claude compatibility remains unverified.
- SDK request defaults increased to 120 seconds for slow model transfers; original task and independent download recovery remain unchanged.
- Versioned archives, client source and SHA-256 checksums. npm and PyPI registry listings are not included in this release.
